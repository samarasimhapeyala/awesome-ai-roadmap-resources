# Stage 1: Core Foundations

> The maths, Python and statistics everything else is built on.

## 1.1 Math Foundations

_Math_

Calculus, Linear Algebra, and Probability fundamentals. All distributions, CDF, PDF, matrix operations, correlation, and confidence intervals.

- [Coursera: Mathematics for Machine Learning](https://www.coursera.org/specializations/mathematics-machine-learning)
- [3Blue1Brown: Linear Algebra series](https://www.3blue1brown.com/topics/linear-algebra)
- [Coursera: AI for Everyone](https://www.coursera.org/learn/ai-for-everyone)
- [Coursera: Introduction to AI](https://www.coursera.org/learn/introduction-to-ai)
- [Khan Academy: Multivariable Calculus](https://www.khanacademy.org/math/multivariable-calculus)
- [StatQuest: Statistics Fundamentals](https://statquest.org/video-index/)
- [YouTube: MIT 18.06 Linear Algebra (Gilbert Strang)](https://www.youtube.com/playlist?list=PLE7DDD91010BC51F8)
- [YouTube: Math for Machine Learning](https://www.youtube.com/playlist?list=PLiolyI-ebvnXZIEdH02hZ4P_O_Z-xEqbC)

## 1.2 Python & R — Medium Depth

_Programming_

IDEs, basic operators, control flows, data structures, functions, file handling, exception handling, and debugging. Standard libraries, packages, version control with Git, and computational complexity analysis.

- [Analytics Vidhya: Intro to Data Science](https://courses.analyticsvidhya.com/courses/introduction-to-data-science)
- [Coursera: Python Specialization](https://www.coursera.org/specializations/python)
- [YouTube: Python for Data Science Playlist](https://www.youtube.com/playlist?list=PLZoTAELRMXVNUL99R4bDlVYsncUNvwUBB)
- [Kaggle: Python Micro-Course](https://www.kaggle.com/learn/python)
- [Real Python: Python Basics](https://realpython.com/learning-paths/python-basics/)
- [YouTube: Corey Schafer Python Tutorials](https://www.youtube.com/user/schafer5)
- [YouTube: freeCodeCamp Python Full Course](https://www.youtube.com/watch?v=rfscVS0vtbw)

## 1.3 Data Visualization & Stats Analysis

_Data Prep_

Pandas, NumPy, Seaborn, and Scikit-learn visualization. Data collection, reading formats, representation, all plots, univariate, bivariate, and multivariate analysis.

- [Kaggle: Data Visualization](https://www.kaggle.com/learn/data-visualization)
- [Coursera: Applied Plotting, Charting & Data Representation](https://www.coursera.org/learn/python-plotting)
- [YouTube: Seaborn Tutorial](https://www.youtube.com/watch?v=6GUOAB0PcgI)
- [YouTube: StatQuest with Josh Starmer](https://www.youtube.com/user/joshstarmer)
- [YouTube: Alex The Analyst Data Viz](https://www.youtube.com/watch?v=1sJvE9k4xEY&list=PLUaB-1hjhk8FhI2-X6-3zYtWn91nE2X2I)
